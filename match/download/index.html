Install

  1. In SketchUp open Extension Manager (Window menu) and click Install Extension.
  2. Choose the .rbz file you downloaded and confirm. No restart is needed.
  3. Parasolv Match appears under the Camera menu and as a toolbar. The Quick Start Tutorial opens the first time you launch it.

Updating

Install the new file the same way. It replaces the previous version in place; your matched scenes, camera history and settings are kept. Parasolv Match also checks for updates itself and offers this page when a newer version exists.

Trying it

Your first complete view match is free, with no account needed. After that a subscription unlocks unlimited matching, and the license key you receive activates on up to two computers.
